# 샘플 데이터 안내

`indicators_sample.csv` — 11개 읍면동 × 56개 지표, numpy seed 42 난수(감마분포)로 만든 **합성 데이터**. 실제 양주시 지표 값·정의와 무관하다.

- 첫 컬럼 `읍면동`, 이어서 `분야_지표명` 형식의 56개 컬럼(인구 8 · 경제 8 · 생활환경 8 · 교통 8 · 교육 8 · 안전 8 · 보건복지 8).
- 지표명 끝의 `(역)`은 값이 클수록 불리한 **역방향 지표**를 뜻하며, 노트북의 음수 변환 → Min-Max 표준화 대상에 해당한다.
- 대응 코드: `03_Gini_coefficient.ipynb`의 `gini(df)`(컬럼별 지니계수)와 `apply_minmax_scaler(df)`(0–1 정규화) 입력 형태.
- 실제 지표 구성은 노트북 `01_demographic_structure_hjd.ipynb`의 산출 컬럼을 참고 (원천 미포함).
